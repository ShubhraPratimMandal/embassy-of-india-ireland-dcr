# Embassy of India to Ireland | DCR

A heavily detailed fictional diplomatic portal for the **Embassy of the Republic of India to Ireland within Dublin City Roleplay**.

## Included
- Embassy mission and departmental directory
- Diplomatic affairs and bilateral relations
- Consular services and fictional visa portal
- Embassy Staff, Diplomatic Service and Consular Service applications
- Public diplomatic record / timeline
- Newsroom and public statements
- Premises and security framework
- Recruitment, protocol and visa documentation
- Responsive static website suitable for GitHub Pages

## Roleplay Disclaimer
This project is a fictional DCR/ERLC roleplay institution. It is not an official Government of India or Government of Ireland website and has no real-world diplomatic, immigration, legal or governmental authority.
